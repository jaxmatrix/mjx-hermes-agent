# Paths where UNIVERSAL's version wins, even though desktop is the reference.
#
# Everything not listed here takes desktop's file verbatim. A path listed here
# is never overwritten by the sync script:
#
#   - present in both, contents differ  -> MERGE  (a human folds desktop's
#                                                  changes into universal's file)
#   - present in both, identical        -> SKIP   (nothing to do)
#   - desktop-only                      -> REVIEW (not copied; a desktop file
#                                                  landing inside a protected
#                                                  subsystem needs a decision)
#
# Globs are relative to `src/` and support `*` (no slash) and `**` (any).
# Scope is `src/` only — package.json, tsconfig.json and vite.config.ts are
# aligned by hand in phase 1, and vite.config.ts must survive verbatim because
# it carries the observability transforms and the Tauri aliases.
